      How it works

      From request to native project

      The AI never writes raw code into your project. It writes a plan, the plan is checked, and Titan’s own elements are built from it.

      1

      You start

      A prompt, a design file, a web address or a FORM1 form, plus any answers to one round of questions.

      input
      2

      A plan is written

      Your AI provider writes a content plan: pages, fields, rules, translations and Salesforce mappings. Design files skip this for the look.

      content plan
      3

      The plan is checked

      Known mistakes are caught, such as a hidden field with no rule to show it. If needed, one targeted correction round runs.

      validated plan
      4

      Titan elements are built

      Native elements, desktop, tablet and phone layouts, logic flows, Salesforce actions and every language.

      Titan project
      5

      Saved and checked

      The project is saved, a quick QA pass runs, and you get a summary of what was built and anything left out.

      ready to review

      Native, not hidden code

      Everything is built from the same elements your team uses by hand: Stepper, PowerTable, Repeat, Counter, Badge, Drawer, SmartV login. Nothing is locked inside custom scripts.

      • Editable by hand. Open any element in the Titan editor and change it as usual.
      • Every device layer. Desktop, tablet and phone layouts are written, not left to chance.
      • Logic in Titan flows. Show and hide rules, validation and navigation live in the project’s own flows.

      Privacy and security

      The extension has no servers of its own and collects nothing about you.

      • Your own AI key. Stored only in your browser and sent only to the provider you chose.
      • Direct to the provider. Requests go from your browser to the AI provider, with no proxy in between.
      • Titan sites only. Runs on formtitan.com and docstitan.com. Other sites need your explicit, one-time permission.
      • No analytics or tracking. Bug reports are saved to your computer and shared only if you choose.

      Guides

      Step by step

      Short guides for the most common jobs. Open one to see the steps.

      Get started

      Install, connect your AI provider and build your first project.

      3 min
      1. Add Titan AI Studio to Chrome from the Chrome Web Store.
      2. Open any project in FormTitan or DocsTitan. The AI Studio panel appears on the right side of the editor.
      3. Open Settings in the panel and paste your API key for OpenAI, Anthropic, Google Gemini or Groq.
      4. Describe what you need and press Send. When the build finishes, the editor reloads with your new pages.

      Write a prompt that builds well

      What to include so the first build is close to final.

      4 min
      • Who uses it, and what they come to do.
      • The pages or steps, in order.
      • The fields that matter, and which are required.
      • What happens on submit: email, Salesforce record, redirect.
      • Languages, if more than one.
      Build a 4-step loan application for Harbor Credit Union members.
Steps: About you, Employment, Loan details, Review.
Show "Co-applicant" fields only if "Applying jointly" is Yes.
On submit, create a Salesforce Lead and show a confirmation page.
English and Spanish.

      Build from a design

      Turn a mockup into a working project with its exact look.

      5 min
      1. Drag your design into the panel: a design spec, a design-canvas ZIP, an HTML app or a screenshot.
      2. In the same message, add a short brief for the logic, such as which fields are required and what happens on submit.
      3. Choose the build depth: UI only, or with Salesforce mapping.
      4. Press Send. The look is built from the file, then one logic pass applies your brief. You can undo that pass.
      The design is the source of truth. Colours and fonts are kept exactly, and any low-contrast text is reported rather than changed.

      Rebuild a website or web app

      Bring an existing site into Titan from its address.

      5 min
      1. Paste the web address into the panel and press Send.
      2. Approve one-time access to that site when Chrome asks.
      3. A capture window opens and walks the pages, forms, dialogs and wizard steps. Leave it open until it finishes.
      4. Review the build summary. It lists what was captured and anything that needs your input.

      Edit an existing project

      Change any project in plain words, including ones built by hand.

      2 min
      1. Open the project and the AI Studio panel.
      2. Describe the change, for example “add a phone field after email and make it required”.
      3. To target one element, click Pick, select it on the canvas, then describe the change.
      4. Read the edit summary. It confirms every change and names anything it skipped.

      Convert a FORM1 form

      Move a classic form to a modern web project.

      5 min
      1. Open the form in the FORM1 designer.
      2. In the panel, choose Convert, then pick FormTitan WEB, or the new builder if your account has early access.
      3. Answer any questions. Each question is asked only once.
      4. The new project opens in a new tab. Your FORM1 form stays unchanged.
      5. Check the conversion report for any rule or integration that needs a manual step.

      Test with QA Studio

      Audit a project and run real test scenarios in Preview.

      6 min
      1. Click Preview in the Titan editor. A QA tab appears on the left edge of the page.
      2. Open it and run the audit. You get a design score, a fix-first list and checks grouped by “fix on your side” and “the extension can fix”.
      3. Describe the process in a sentence. QA Studio derives scenarios: every branch, step and required field.
      4. Optionally export the scenarios to Excel, edit the inputs and upload them back.
      5. Start the live run. Watch each step, and pause, stop or take over at any time.
      Salesforce writes during a test run go only to a sandbox org, never to production.

      Common questions

      Editing, checks, data and supported AI models.

      FAQ
      • Can I edit what it builds by hand? Yes. Everything is built from standard Titan elements.
      • Is every build checked? Yes. Every build ends with a summary of what was made and a quick QA pass.
      • Which AI should I use? Any of the four supported providers works. Larger models give richer first builds.
      • Does my data go to Titan? No. Requests go from your browser straight to the AI provider you chose.
